## 1. 핵심 개념

### Linux

Linux는 컴퓨터의 CPU, 메모리, 저장장치 같은 하드웨어와 프로그램 사이를 연결하는 **커널**입니다. 서버, 클라우드, 네트워크 장비와 보안 실습 환경에서 널리 사용됩니다.

```text
사용자
  ↓
프로그램
  ↓
Linux 커널
  ↓
CPU / 메모리 / 저장장치 / 네트워크
```

### Ubuntu

Ubuntu는 Linux 커널과 여러 프로그램을 함께 묶어 사용하기 쉽게 만든 **Linux 배포판**입니다.

```text
Linux 기반 배포판
├── Ubuntu
├── Debian
├── Fedora
├── Arch Linux
└── Kali Linux
```

### GUI와 CLI

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| GUI | 창, 아이콘, 마우스로 컴퓨터를 사용하는 방식 | 파일 관리자, 설정 창, 웹 브라우저 |
| CLI | 문자 명령어를 입력해 컴퓨터를 사용하는 방식 | `pwd`, `ls`, `cd` |

보안과 서버 환경에서는 원격 시스템을 다루거나 반복 작업을 자동화할 때 CLI를 자주 사용합니다.

### Terminal

Terminal은 사용자가 명령어를 입력하고 결과를 확인하는 **프로그램**입니다. Ubuntu에서는 `Ctrl` + `Alt` + `T`로 터미널을 열 수 있습니다.

터미널 프롬프트는 보통 다음과 비슷합니다.

```text
user@ubuntu:~$
```

- `user`: 현재 사용자 이름
- `ubuntu`: 컴퓨터 이름
- `~`: 현재 위치가 홈 디렉터리임을 나타냄
- `$`: 일반 사용자 권한으로 실행 중임을 나타냄

### Shell

Shell은 터미널에 입력한 명령어를 해석해 운영체제에 전달하는 프로그램입니다. Ubuntu에서는 보통 Bash를 사용합니다.

```text
사용자 → Terminal → Shell → Linux → 실행 결과
```

현재 Shell 확인:

```bash
echo $SHELL
```

예상 결과:

```text
/bin/bash
```

### 루트 디렉터리 `/`

Linux 파일 시스템의 가장 위에는 **루트 디렉터리** `/`가 있습니다. Windows의 드라이브 문자와 달리 Linux의 디렉터리와 장치는 하나의 `/` 아래에 연결됩니다.

```text
/
├── home    일반 사용자의 개인 디렉터리
├── etc     시스템 설정 파일
├── usr     프로그램과 공유 데이터
├── var     로그처럼 자주 변하는 데이터
├── tmp     임시 파일
└── root    root 사용자의 홈 디렉터리
```

일반 사용자의 홈 디렉터리는 보통 `/home/사용자이름`입니다. Day 01에는 구조를 관찰하기만 하고 시스템 파일은 수정하지 않습니다.

## 2. 오늘의 명령어

| 명령어 | 역할 |
| --- | --- |
| `whoami` | 현재 로그인한 사용자 이름을 확인한다. |
| `pwd` | 현재 작업 중인 디렉터리의 전체 경로를 확인한다. |
| `ls` | 현재 디렉터리의 파일과 디렉터리 목록을 본다. |
| `ls -l` | 파일 목록을 자세한 형식으로 본다. |
| `ls -a` | 이름이 `.`으로 시작하는 숨김 파일까지 본다. |
| `ls -la` | 숨김 파일을 포함한 목록을 자세한 형식으로 본다. |
| `clear` | 터미널 화면의 이전 출력을 정리한다. |

### `whoami`

현재 로그인한 사용자를 확인합니다.

```bash
whoami
```

### `pwd`

`Print Working Directory`의 약자로, 현재 위치의 전체 경로를 출력합니다.

```bash
pwd
```

예상 결과:

```text
/home/user
```

### `ls`

현재 디렉터리의 파일과 디렉터리 목록을 출력합니다.

```bash
ls
```

### `ls -l`

파일 종류, 권한, 소유자, 크기, 수정 시간 등을 포함한 자세한 목록을 출력합니다.

```bash
ls -l
```

Day 01에는 각 항목의 의미를 모두 외우지 않아도 됩니다. 파일 권한은 이후 주차에서 자세히 학습합니다.

### `ls -a`

숨김 파일을 포함한 모든 항목을 출력합니다.

```bash
ls -a
```

Linux에서는 이름이 `.`으로 시작하는 파일을 일반적으로 숨김 파일로 취급합니다.

```text
.bashrc
.profile
.config
```

출력에 나타나는 `.`은 현재 디렉터리, `..`은 상위 디렉터리를 뜻합니다.

### `ls -la`

`-l`과 `-a` 옵션을 함께 사용합니다.

```bash
ls -la
```

즉, **숨김 파일을 포함한 모든 항목을 자세한 형식으로 출력**합니다.

### `clear`

터미널 화면을 정리합니다. 파일이나 명령어 기록을 삭제하는 명령어는 아닙니다.

```bash
clear
```

## 3. 실습

### 실습 1 — 내 Ubuntu 환경 확인

다음 명령어를 순서대로 실행합니다.

```bash
whoami
hostname
pwd
uname -a
cat /etc/os-release
```

관찰할 내용:

- 내 사용자 이름은 무엇인가?
- 컴퓨터 이름은 무엇인가?
- 현재 위치는 어디인가?
- 설치된 Ubuntu 버전은 무엇인가?

### 실습 2 — 파일 목록 비교

```bash
ls
ls -l
ls -a
ls -la
```

관찰할 내용:

- `ls`와 `ls -a`의 결과는 어떻게 다른가?
- `ls -l`을 사용했을 때 어떤 정보가 추가되는가?
- `.bashrc`, `.profile`, `.config`와 같은 숨김 항목이 있는가?

### 실습 3 — 위치와 목록 연결하기

```bash
pwd
ls
```

예를 들어 `pwd` 결과가 `/home/user`이고 `ls` 결과가 다음과 같다면:

```text
Desktop  Documents  Downloads
```

현재 구조를 다음과 같이 연결해 생각할 수 있습니다.

```text
/home/user
├── Desktop
├── Documents
└── Downloads
```

### 실습 4 — 홈 디렉터리의 숨김 파일 관찰

```bash
ls -la
```

` . `으로 시작하는 항목을 찾아봅니다. Day 01에는 숨김 설정 파일을 수정하거나 삭제하지 않습니다.

### 실습 5 — 명령어 반복

```bash
clear
whoami
pwd
ls
ls -a
ls -l
ls -la
```

터미널을 닫았다 다시 열고, 문서를 보지 않은 상태에서 한 번 더 실행합니다.
