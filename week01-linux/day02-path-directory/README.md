# Day 02 — 경로와 디렉터리

## 학습 목표

- 절대경로와 상대경로를 구분한다.
- `.`, `..`, `~`, `/`의 의미를 설명한다.
- 디렉터리를 생성하고 원하는 위치로 이동한다.

## 학습 예정 내용

```bash
pwd
cd
mkdir
rmdir
```

## 완료 기준

- [ ] `/home/user/test`와 `../test`의 차이를 설명할 수 있다.
- [ ] `mkdir`로 실습 디렉터리를 만들 수 있다.
- [ ] `cd`로 홈, 상위, 루트 디렉터리를 이동할 수 있다.
- [ ] 실습 결과와 배운 점을 이 문서에 기록했다.
