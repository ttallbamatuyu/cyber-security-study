# Day 02 — 경로 이해와 디렉터리 이동

> 작성일: 2026-07-29  
> 권장 학습 시간: 1시간 30분~2시간

오늘은 Linux 파일 시스템에서 현재 위치를 파악하고, 절대경로와 상대경로를 이용해 원하는 디렉터리로 이동하는 방법을 학습합니다.

- [ ] `pwd`로 현재 위치를 확인할 수 있다.
- [ ] `cd`로 원하는 디렉터리로 이동할 수 있다.
- [ ] `mkdir`로 디렉터리를 만들 수 있다.

- [ ] `rmdir`로 비어 있는 디렉터리를 삭제할 수 있다.

## 1. Linux 디렉터리 구조

Linux의 모든 파일과 디렉터리는 최상위 디렉터리인 `/` 아래에 있습니다.

```text
/
├── home
│   └── 사용자이름
├── etc
├── usr
├── var
├── tmp
└── root
```

- `/`: 전체 파일 시스템의 시작점인 루트 디렉터리
- `/home/사용자이름`: 일반 사용자의 홈 디렉터리
- `/root`: 관리자 계정인 `root` 사용자의 홈 디렉터리

현재 사용자와 위치 확인:

```bash
whoami
pwd
```

---

## 2. 절대경로

절대경로는 **루트 디렉터리 `/`부터 시작하는 전체 경로**입니다.

```text
/home/user/Documents
/etc
/usr/bin
```

가장 중요한 특징은 현재 위치가 어디든 항상 같은 대상을 가리킨다는 점입니다.

```bash
cd /tmp
pwd
```

예상 결과:

```text
/tmp
```

### 핵심

```text
절대경로 = /로 시작하는 전체 경로
```

---

## 3. 상대경로

상대경로는 **현재 작업 디렉터리를 기준으로 표현하는 경로**입니다.

현재 위치가 `/home/user`이고 그 안에 `Documents` 디렉터리가 있다면:

```bash
cd Documents
```

처럼 이동할 수 있습니다.

같은 위치를 절대경로로 표현하면:

```bash
cd /home/user/Documents
```

두 명령어가 같은 위치로 이동할 수 있지만, 상대경로의 결과는 명령을 실행하는 현재 위치에 따라 달라집니다.

### 핵심

```text
상대경로 = 현재 위치를 기준으로 하는 경로
```

---

## 4. 반드시 알아야 하는 경로 기호

| 기호 | 의미 | 예시 |
| --- | --- | --- |
| `/` | 루트 디렉터리 | `cd /` |
| `~` | 현재 사용자의 홈 디렉터리 | `cd ~` |
| `.` | 현재 디렉터리 | `cd .` |
| `..` | 상위 디렉터리 | `cd ..` |

### `/` — 루트 디렉터리

Linux 파일 시스템의 가장 위에 있는 디렉터리입니다.

```bash
cd /
pwd
```

결과:

```text
/
```

### `~` — 홈 디렉터리

현재 사용자의 개인 디렉터리를 나타냅니다.

```bash
cd ~
pwd
```

예상 결과:

```text
/home/사용자이름
```

`cd`만 입력해도 홈 디렉터리로 이동합니다.

```bash
cd
```

> `~`는 Shell이 현재 사용자의 홈 디렉터리 경로로 확장해서 처리합니다.

### `.` — 현재 디렉터리

현재 작업 중인 디렉터리를 나타냅니다.

```bash
cd .
```

현재 위치에서 현재 위치로 이동하므로 경로는 바뀌지 않습니다.

### `..` — 상위 디렉터리

현재 위치보다 한 단계 위에 있는 디렉터리를 나타냅니다.

```bash
cd ..
```

현재 위치가 `/home/user/Documents`라면 실행 후 `/home/user`로 이동합니다.

두 단계 위로 이동:

```bash
cd ../..
```

## 5. 오늘의 명령어

| 명령어 | 기능 |
| --- | --- |
| `pwd` | 현재 작업 디렉터리의 전체 경로를 출력한다. |
| `ls` | 현재 디렉터리의 내용을 확인한다. |
| `cd 경로` | 지정한 경로로 이동한다. |
| `cd ..` | 상위 디렉터리로 이동한다. |
| `cd ~` 또는 `cd` | 홈 디렉터리로 이동한다. |
| `cd -` | 바로 이전 작업 디렉터리로 이동한다. |
| `mkdir 이름` | 새 디렉터리를 만든다. |
| `mkdir -p 경로` | 필요한 상위 디렉터리까지 함께 만든다. |
| `rmdir 이름` | 비어 있는 디렉터리를 삭제한다. |

## 6. `cd`로 디렉터리 이동하기

### 홈 디렉터리로 이동

```bash
cd ~
```

또는:

```bash
cd
```

### 루트 디렉터리로 이동

```bash
cd /
```

### 상위 디렉터리로 이동

```bash
cd ..
```

### 현재 위치 안의 디렉터리로 이동

```bash
cd Documents
```

### 절대경로로 이동

```bash
cd /home/사용자이름/Documents
```

### 이전 위치로 돌아가기

```bash
cd /tmp
cd ~
cd -
```

마지막 `cd -`를 실행하면 직전에 있던 `/tmp`로 돌아갑니다.

---

## 7. `mkdir`로 디렉터리 만들기

디렉터리 하나 만들기:

```bash
mkdir practice
```

여러 디렉터리를 한 번에 만들기:

```bash
mkdir day1 day2 day3
```

중간 디렉터리까지 한 번에 만들기:

```bash
mkdir -p linux-study/week01/day02
```

확인:

```bash
ls
```

`tree`가 설치되어 있다면:

```bash
tree linux-study
```

---

## 8. `rmdir`로 빈 디렉터리 삭제하기

```bash
mkdir empty-directory
rmdir empty-directory
```

`rmdir`은 **비어 있는 디렉터리만 삭제**할 수 있습니다. 내부에 파일이나 디렉터리가 있으면 다음과 비슷한 오류가 발생합니다.

```text
rmdir: failed to remove '이름': Directory not empty
```

내용이 있는 디렉터리를 지우는 `rm -r`은 잘못된 경로에 사용하면 중요한 파일을 함께 삭제할 수 있으므로 Day 03에서 안전 수칙과 함께 학습합니다.

## 9. 단계별 실습

### 실습 1 — 주요 위치 이동

다음 명령어를 한 줄씩 입력하고, 이동할 때마다 `pwd`로 위치를 확인합니다.

```bash
pwd

cd /
pwd

cd /tmp
pwd

cd ~
pwd

cd ..
pwd

cd ~
pwd
```

### 실습 2 — 연습 디렉터리 만들기

```bash
cd ~
mkdir -p linux-practice/day02
cd linux-practice/day02
pwd
mkdir documents backup practice
ls
```

예상 구조:

```text
day02/
├── backup/
├── documents/
└── practice/
```

### 실습 3 — 상대경로로 이동

```bash
cd ~/linux-practice/day02
pwd

cd documents
pwd

cd ..
pwd

cd backup
pwd

cd ../documents
pwd
```

`backup`에서 `../documents`로 이동할 때:

1. `..`로 `day02`에 올라갑니다.
2. 같은 위치의 `documents`로 들어갑니다.

### 실습 4 — 절대경로와 상대경로 비교

홈 디렉터리에서 시작합니다.

```bash
cd ~
```

절대경로로 이동합니다. `사용자이름`은 `whoami` 결과로 바꿉니다.

```bash
cd /home/사용자이름/linux-practice/day02/documents
pwd
```

홈으로 돌아온 뒤 상대경로로 이동:

```bash
cd ~
cd linux-practice/day02/documents
pwd
```

두 방법의 최종 위치가 같은지 확인합니다.

> `~/linux-practice/...`도 같은 위치를 가리킬 수 있지만, `~`는 `/`로 시작하는 경로 자체가 아니라 Shell이 홈 디렉터리 경로로 확장하는 기호입니다.

### 실습 5 — 이전 위치로 돌아가기

```bash
cd /tmp
pwd

cd ~
pwd

cd -
pwd
```

마지막 결과가 `/tmp`라면 정상입니다.

### 실습 6 — 빈 디렉터리 삭제

```bash
cd ~/linux-practice/day02
mkdir empty-directory
ls
rmdir empty-directory
ls
```

삭제 전후 목록을 비교합니다.

## 10. Day 02 종합 미션

명령어만 사용해 다음 구조를 만듭니다.

먼저 홈 디렉터리로 이동해 시작 위치를 통일합니다.

```bash
cd ~
```

```text
day02-mission/
├── notes/
├── commands/
└── test/
    ├── level1/
    └── level2/
```

사용할 수 있는 명령어:

```bash
mkdir
mkdir -p
cd
pwd
ls
```

완성 후 확인:

```bash
tree day02-mission
```

`tree`가 없다면:

```bash
ls -R day02-mission
```

### 이동 미션

`day02-mission`이 홈 디렉터리 아래에 있다고 가정합니다.

1. 절대경로를 사용해 `level2`로 이동한다.
2. `pwd`로 현재 위치를 확인한다.
3. `..`을 사용해 `test`로 이동한다.
4. 상대경로로 `level1`에 이동한다.
5. 홈 디렉터리로 이동한다.
6. `cd -`로 직전 위치에 돌아간다.

## 11. 자가 테스트

답을 보기 전에 자신의 말로 설명합니다.

1. `/home/user/Documents`와 `Documents` 중 절대경로는 무엇인가?
2. 현재 위치가 `/home/user/Documents`일 때 `cd ..` 실행 후 위치는 어디인가?
3. `/`와 `~`의 차이는 무엇인가?
4. 현재 디렉터리와 상위 디렉터리는 각각 어떤 기호로 나타내는가?
5. `cd /home/user/Documents`와 `cd Documents`의 차이는 무엇인가?
6. `cd -`는 무엇을 하는가?
7. `mkdir -p`는 언제 사용하는가?
8. 비어 있는 `test` 디렉터리를 삭제하는 명령어는 무엇인가?
9. `rmdir`로 내용이 있는 디렉터리를 삭제할 수 있는가?

<details>
<summary>자가 테스트 답안 보기</summary>

1. `/home/user/Documents`
2. `/home/user`
3. `/`는 전체 파일 시스템의 루트 디렉터리이고, `~`는 현재 사용자의 홈 디렉터리이다.
4. 현재 디렉터리는 `.`, 상위 디렉터리는 `..`이다.
5. 첫 번째는 `/`로 시작하는 절대경로이고, 두 번째는 현재 위치를 기준으로 하는 상대경로이다.
6. 바로 이전에 작업하던 디렉터리로 이동한다.
7. 필요한 상위 디렉터리를 포함한 중첩 구조를 한 번에 만들 때 사용한다.
8. `rmdir test`
9. 삭제할 수 없다. `rmdir`은 비어 있는 디렉터리만 삭제한다.

</details>
