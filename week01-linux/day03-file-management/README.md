# Day 03 — 파일 생성·복사·이동·삭제

## 학습 목표

- 파일을 생성하고 복사한다.
- 파일을 이동하거나 이름을 변경한다.
- 정확한 대상을 확인한 뒤 파일을 삭제한다.

## 학습 예정 내용

```bash
touch
cp
mv
rm
mkdir
```

## 완료 기준

- [ ] `touch`로 파일을 만들 수 있다.
- [ ] `cp`로 파일을 복사할 수 있다.
- [ ] `mv`로 파일을 이동하고 이름을 변경할 수 있다.
- [ ] 삭제 전에 `pwd`와 `ls`로 대상을 확인하는 습관을 익혔다.
- [ ] 실습 결과와 배운 점을 이 문서에 기록했다.
