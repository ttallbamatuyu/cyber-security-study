# Day 04 — 파일 내용과 리다이렉션

## 학습 목표

- 파일의 전체 또는 일부 내용을 확인한다.
- 표준 출력을 파일에 저장한다.
- `>`와 `>>`의 차이를 설명하고 안전하게 사용한다.

## 학습 예정 내용

```bash
cat
less
head
tail
echo
>
>>
```

## 완료 기준

- [ ] `cat`과 `less`로 파일 내용을 확인할 수 있다.
- [ ] `head`와 `tail`로 파일 앞부분과 뒷부분을 확인할 수 있다.
- [ ] `>`는 덮어쓰기, `>>`는 이어쓰기임을 설명할 수 있다.
- [ ] 실습 결과와 배운 점을 이 문서에 기록했다.
