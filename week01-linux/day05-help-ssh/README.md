# Day 05 — 명령어 도움말과 SSH

## 학습 목표

- 모르는 명령어의 사용법을 스스로 찾는다.
- SSH의 목적과 기본 접속 형식을 설명한다.
- SSH 클라이언트로 학습용 원격 서버에 접속한다.

## 학습 예정 내용

```bash
명령어 --help
man 명령어
ssh 사용자명@서버주소
ssh -p 포트번호 사용자명@서버주소
```

## 완료 기준

- [ ] `--help`와 `man`을 사용할 수 있다.
- [ ] SSH가 암호화된 원격 접속 프로토콜임을 설명할 수 있다.
- [ ] 사용자, 서버 주소, 포트의 역할을 구분할 수 있다.
- [ ] 실습 결과와 배운 점을 이 문서에 기록했다.
