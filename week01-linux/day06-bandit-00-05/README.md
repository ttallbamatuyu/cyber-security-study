# Day 06 — OverTheWire Bandit Level 0~5

## 학습 목표

- 1주차에 배운 Linux 명령어를 워게임에 적용한다.
- 문제를 읽고 파일과 디렉터리를 단계적으로 조사한다.
- 정답보다 문제 해결 과정과 새롭게 배운 점을 기록한다.

## 문제 접근 순서

```text
현재 위치 확인
    ↓
파일과 숨김 파일 목록 확인
    ↓
파일과 디렉터리 구분
    ↓
필요한 명령어의 도움말 확인
    ↓
파일 내용 확인
    ↓
풀이 과정 기록
```

## 진행 상황

- [ ] Level 0
- [ ] Level 1
- [ ] Level 2
- [ ] Level 3
- [ ] Level 4
- [ ] Level 5

## 기록 시 주의

- Bandit 비밀번호는 GitHub에 커밋하지 않는다.
- 사용한 명령어와 그 명령어를 선택한 이유를 기록한다.
- 바로 정답을 검색하기 전에 `man`과 `--help`를 활용한다.

> 각 Level을 해결한 뒤 문제 요약, 접근 방법, 사용 명령어와 배운 점을 추가합니다.
