# Day 07 — 종합 복습과 학습 기록 정리

## 학습 목표

- 1주차 명령어를 검색 없이 사용한다.
- 디렉터리와 파일을 요구사항에 맞게 구성한다.
- 학습 내용을 검토하고 다음 주차 준비 사항을 정리한다.

## 종합 미션

```text
week1-test/
├── notes/
│   ├── linux.txt
│   └── ssh.txt
└── backup/
```

- [ ] 위 디렉터리 구조를 만든다.
- [ ] `linux.txt` 첫 줄을 `>`로 작성한다.
- [ ] 두 번째 줄을 `>>`로 추가한다.
- [ ] `linux.txt`를 `backup/linux_backup.txt`로 복사한다.
- [ ] `.secret` 숨김 파일을 만들고 `ls -la`로 확인한다.
- [ ] `man cp`에서 옵션 하나를 찾아 설명한다.

## 주간 자가 점검

- [ ] `pwd`, `ls`, `cd`, `mkdir`를 설명할 수 있다.
- [ ] 절대경로와 상대경로를 설명할 수 있다.
- [ ] 파일 생성·복사·이동·삭제를 수행할 수 있다.
- [ ] `>`와 `>>`의 차이를 설명할 수 있다.
- [ ] SSH의 목적을 설명할 수 있다.
- [ ] Bandit Level 0~5의 풀이 과정을 비밀번호 없이 기록했다.

> 복습을 마친 뒤 어려웠던 부분, 다시 공부할 부분과 2주차 목표를 추가합니다.
